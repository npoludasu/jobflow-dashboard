# 🚀 JobFlow Dashboard

A modern job application tracking dashboard to manage job applications efficiently.

---

## 🔥 Features
- Track job applications
- Manage job status (Applied, Interview, Offer, Rejected)
- Clean and responsive UI
- Easy navigation and filtering

---

## 🛠️ Tech Stack
- React.js
- JavaScript (ES6+)
- Tailwind CSS
- Local Storage 

---
## 🌐 Live Demo
https://jobflow-dashboard-ngr1.vercel.app/

---


## ⚙️ Run Locally

git clone https://github.com/npoludasu/jobflow-dashboard.git

cd jobflow-dashboard

npm install

npm start
